Clone X — Projet Full-Stack

Kadea Academy - Kinshasa

Octobre 2025

Clone X est une application web inspirée de Twitter/X, développée avec AdonisJS 6, le moteur de templates Edge, et PostgreSQL comme base de données. Elle permet la gestion complète d’un réseau social miniature : comptes utilisateurs, authentification sécurisée, tweets, likes, follows, hashtags et intégration d’une IA (Grok).

  • Comptes utilisateurs : Inscription, connexion, déconnexion Vérification par e-mail Réinitialisation et changement de mot de passe Profil (avatar, bio, confidentialité)

  • Tweets : Création, modification, suppression Ajout d’images/médias Réponses, likes, retweets Timeline des comptes suivis

  • Suivi et relations : Follow / Unfollow, demandes de follow (compte privé), bloquer ou débloquer un utilisateur,

Projet réalisé dans le cadre du module Développement Web Full-Stack avec AdonisJS 6. Lien du repo :
